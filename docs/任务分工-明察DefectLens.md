# 任务分工 · 明察 DefectLens

> 这份文档管**谁在什么时间交付什么**。团队是 1 名算法主责 + 2 名 AI 开发主责；三人都能参与算法，按交付物划主责与协作，不按“前端 / 后端 / 算法”硬隔开。
> 版本：v1（2026-10-13）。任务状态随执行更新，**完成一项勾一项，不许自报完成**。

---

## 一、角色与职责

| 角色 | 谁 | 主责 | 同时参与的算法工作 | 验收重点 |
|---|---|---|---|
| **队员 A** | 算法主责，做过图像分割 | 数据与模型主线：baseline 复现、分割、严重度头、训练和消融设计 | 与 C 共同定义指标口径；与 B 确定模型输出和边界样本 | 每次实验有配置、模型版本、数据划分和可复核指标 |
| **队员 B** | AI 开发主责（你） | AgentArts 编排、工作台、插件接入、演示闭环与材料整合 | 参与推理后处理、置信度校准、边界样本分析和 Agent 决策策略；可承担独立消融 | 平台确实调用模型服务，界面和处置记录能追溯到同一结果 |
| **队员 C** | AI 开发主责 | 数据管线、模型服务、评测脚本、实验管理与部署 | 与 A 一起复现 baseline、跑训练和消融，负责误差分析及可复现评测 | 模型可稳定调用，指标脚本和实验记录可复核 |
| **指导老师** | — | 算力与方向把关 | — | 卡型、显存、可用时长明确 |

**协作原则**：A 对模型方案和实验结论负责，但不独自承担所有算法任务；C 常态参与训练、评测和误差分析，B 负责与产品决策直接相关的后处理和边界样本实验。关键改动先约定数据划分、指标和接口，再分头实现；结论由另一人复核。

## 三、关键路径与卡点

```
0.2 卡型确认 → 0.4 第一个 mIoU → 2.2 复现 → 2.3/2.4 改进 → 3.2 实测指标
                                                              ↓
0.1 数据回信（第 5 天硬截止）──────────────────────────────→ 材料数字
0.3 AgentArts 跑通 → 1.3 公网 + 插件 → 2.5 三角色 → 2.6 视频
0.6 公网方案 ────────↑（卡住 1.3 与决赛 Demo 页面）
```

**当前三个卡点**：① 数据回信（被动等）；② 卡型未确认（问老师，10 分钟）；③ 公网方案未拍板（0.6）。

## 四、沟通与汇报

1. **周节奏**：每周固定一次 30 分钟同步，三线各报三件事——做完什么 / 卡在哪 / 下周做什么；
2. **口径只在文档里**：`硬约束` 与 `答辩问答口径` 是对外唯一口径来源，**不在群里口头传**，谁传谁改回来；
3. **坏消息不过夜**：卡住超过半天就在同步会上说，不许自己扛到截止日；
4. **完成标准**：任务验收栏全过才算完成，自报完成不算。
