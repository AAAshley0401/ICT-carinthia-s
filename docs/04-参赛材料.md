# 毫芒 Hairline｜参赛材料提纲

更新：2026-10-13。具体提交格式、评分和截止时间以本届官方通知为准，提交前复核。

## 材料主线

1. **问题与场景**：晶圆显微图缺陷不仅要“找得到”，还要回答严重度和处置；目标用户为质检员及复核工程师。
2. **方案**：定位与序数分级模型提供证据，AgentArts 按置信度分流并处理边界样本；展示角色输入、工具调用和输出，避免只展示聊天界面。
3. **验证**：官方 baseline 复现、相同条件下的单变量消融、三指标和错误案例。当前结果写“待实测”。
4. **应用价值**：减少重复筛查，让可疑和边界样本进入人工复核；不声称已在产线部署或替代现有设备。
5. **团队**：A 主导模型，B 主导平台和产品，C 主导数据、服务与评测；B/C 同时参与算法。

## 需要的证据

| 主张 | 对应证据 |
|---|---|
| AgentArts 应用真实运行 | 平台调用记录、工具输入输出、演示视频 |
| 缺陷定位与分级有效 | 测试划分、模型版本、mIoU / Macro-F1 / QWK、可视化样例 |
| 改动带来增益 | 同条件 baseline 与单变量消融表 |
| 可用于处置流程 | 不同置信度和边界档样本的分流记录 |

## 对外口径

- 华为 ICT 大赛是参赛场，ICME 2026 已结束的榜单是外部参考；不能暗示本队参加 ICME 2026 或获奖。
- 只有取得相同测试条件并实际计算后，才可写与榜单的分数对比；否则只写公开集上的复现结果。
- 演示图、模拟接口输出、未完成的原型均明确标注“演示”，不填进成绩表。
- 不写“首创”“替代产线设备”等无法证明的表述；市场数据和外部成绩逐项标来源。
