# 初赛材料大纲 · 明察 DefectLens

> 用途：初赛是**函评**，只评书面材料，权重 **创新性 60% + 应用价值 40%**。这份大纲回答一件事——**每一节写什么、素材在哪、现在能不能写。**
> 版本：v1（2026-10-13）。提交形式以官方《作品信息收集表》与通知为准，**临交前再核一次官网**。
> 配套：`方案存档`（技术细节）、`答辩问答口径`（创新性怎么答）、`起跑清单 §〇之三`（官方提交口径）。

---

## 〇、先记住三件事

1. **初赛没有答辩，材料就是全部。** 评委三天看几百份，每份被翻的时间以分钟计。写不清"你补了哪一格"的材料，直接沉。
2. **创新性占 60%，而它是纸面上的。** 不依赖数据、不依赖模型、不依赖 AgentArts——**这是现在唯一能全速推进的权重**。
3. **没跑出来的数字一律写"待实测"**，宁可空着，不许填估计值。材料里出现一个编的数，整套作废。

## 二、逐节大纲

### 第 1 节 作品简介与创意点（评委最先读的一节，最重要）

**要答的问题**：这是什么？跟别人有什么不同？为什么难？

**我们的答案骨架**（照 `方案存档` §〇之二、§一 写）：

- **一句话**：在晶圆表面显微图里定位缺陷，并判断它严重到哪一档（Acceptable / Marginal NG / NG / Gross NG）；整套东西作为质检智能体跑在 AgentArts 上。
- **创意点三条**，按这个顺序写：
  1. **做的是分级，不是检测**——检测（有没有）是红海，分级（多严重）是公认难题，ICME 官方论文原话"序数边界消歧仍是最大障碍"；
  2. **全场短板在哪我们攻哪**——当届冠军 QWK 已 0.907（近顶格），而 mIoU 只有 0.662、Macro-F1 只有 0.673，定位是全场没人解决的那一格；
  3. **数字可被别人验**——同一套冻结测试集、同一套官方公式下独立对标，代码与复现过程公开。
- **配一张图**：`prototype/` 工作台截图（缺陷图 + 定位框 + 四档色带 + 三角色动作）。

**红线**：这一节**不许出现**"首创 / 国内首个 / 填补空白"这类词。创意点写"补的是公认没做完的一格"，不写"没人做过"。

### 第 2 节 行业问题与落地场景

**要答的问题**：这东西谁用？用在哪？不用它会怎样？

**素材**（全部有出处，引用时标来源）：

- 半导体检测市场 2025 年约 90 亿美元、2035 年预计 220 亿（GM Insights）；KLA 一家约一半份额，前五家合计 91.8%——**用来说明行业真实存在、付得起钱，不用来吹自己**；
- 中国本土厂商份额从 2024 年 4.6% 升到 2026 年 9.2%，高端电子束国产化率不足 15%——**国产检测算法是真需求**，这条最值得写；
- 论文动机：器件微型化后人眼与常规 AI 都看不过来；且**跨场景泛化差**，换个产线就掉点——这是学术模型进不了产线的真正原因，也是我们的问题意识从哪来。

**落地场景写具体，别写"智能制造"四个字**：晶圆出厂前的终检环节——同一道划痕，判 Acceptable 就放行，判 NG 就返工。**价值就是良率和返工成本。**

**红线**：**不写"替代 KLA / 替代 AOI 设备"**。它卖单台上千万美元的设备，有装机数据和产线闭环，我们没有。写"可迁移的方法论 + 公开可复现的证据"，天花板低就低，不装。

### 第 3 节 Agent 设计方案（赛题二的正文，官方点名要的四小项）

官方要求写全四项，一项都别漏：**场景定义 / 编排思路 / 工作流架构 / 模型与资产选择**。

| 小项 | 写什么 | 素材 |
|---|---|---|
| **场景定义** | 一批晶圆显微图进来 → 三个角色分工 → 出处置工单（放行/复检/返工） | `方案存档` §一机制表、`fig2-agents` |
| **编排思路** | 为什么是三个角色：分拣（先粗筛，别全量过重模型）/ 检测（定位+分级）/ 仲裁（专收边界样本）。**每个角色要有自己的判断和动作，不是把一次推理拆成三个名字** | `方案存档` §〇之二"防退化成 API 包装"五条 |
| **工作流架构** | 单图路径 + 批量路径 + 人工兜底路径；置信度低时走仲裁 | 架构图（待画，用 `figs/` 同风格） |
| **模型与资产选择** | 检测内核（分割骨干 + 序数头）、AgentArts 上的模型与插件/MCP、知识库（缺陷图谱，供仲裁查） | `起跑清单` §一 AgentArts 组件 |

**这一节决定"这跟 AgentArts 有什么关系"**。要写出**真的 Agent 行为**：自主分流（按置信度决定放行还是送检）、可解释（给出判这一档的视觉证据）、主动上报"我判不准"、跨批次校准阈值。四条全是纯模型没有的行为——这就是赛题二要的东西。

### 第 4 节 技术内核与验证方式（"凭什么信你"）

**要答的问题**：你说做出来了，怎么证明？

**答案**：外部可验证的公开基准对标。

- 尺子：ICME 2026 Track 2 冻结榜，官方公式 `总分 = 0.2×mIoU + 0.2×Macro-F1 + 0.6×QWK`；
- 对标对象：官方 baseline（YOLOv8-seg + 手工规则打分）与当届冠军 0.811（QWK 0.907 / mIoU 0.662 / F1 0.673）；
- 我们的路线：完整复现 → 单变量消融 → 主攻 mIoU，QWK 护栏 0.89；
- **我们的数字：待实测。** 数据到手前这一节如实写"申请中/复现中"，评委看得懂进行时，看不懂吹牛。

**红线（全项目最硬）**：不暗示我们参加过 ICME 或获奖。口径只有一句——**赛事已结束，我们在其公开冻结测试集与公式上做独立对标，并计划投向下一届。**

### 第 5 节 团队介绍

- 3 名学生 + 1 名指导教师（同校，已确认）；
- 分工照 `项目文档` §六：算法（做过图像分割，主攻定位短板）/ 开发×2（AgentArts 外壳 + 评测与数据管线）/ 老师（算力与方向把关）；
- **写法要点**：把分工和技术路线对上——"队伍里唯一做算法的人正好站在全场短板那一项上"，这比罗列技能点更有说服力。

### 第 6 节 Demo 视频

- 内容：AgentArts 上从建智能体到跑通一次完整质检的全过程（官方原话：须体现"基于 AgentArts 构建与运行的完整流程"）；
- **依赖 AgentArts 应用跑通 ⇒ 这是外壳线的 KPI**，与数据无关，现在就能开工；
- 脚本骨架见 `方案存档` §八（Demo 脚本），视频版砍掉现场互动、保留"调用详情"镜头。

## 三、创新性 60% 怎么写（权重最高，专章）

**评委会问的问题**：人家都存在，有人做得比你们好，为什么还要做？

**材料里的标准答法**（与 `答辩问答口径` 完全一致，不许另写一套）：

1. **先承认品类不新**——检测是红海，KLA 占大半个市场；
2. **换问题**——我们做的不是"有没有缺陷"，是"严重到哪一档"；官方论文原话"序数边界消歧仍是最大障碍"，连冠军都没解决；
3. **给数字**——冠军 0.811 的构成（0.907 / 0.662 / 0.673）证明全场都挤在分级、没人解决定位；
4. **收在贡献上**——我们攻全场短板那一格，且数字可被任何人核验。

**这一栏的得分点排序**：可验证的硬指标 > 系统完整性 > 多角色设计。**"多智能体编排"不许当创新点写**——AgentArts 拖拽即有，写了反而暴露没搞清楚平台能力边界。

## 四、应用价值 40% 怎么写

1. **行业真需求**：半导体检测市场数据 + 国产化率低（第 2 节的素材）；
2. **落到具体环节**：终检环节的放行/返工决策，价值是良率与返工成本；
3. **可迁移性**：论文自述"跨场景泛化差"，我们把跨场景下分级成不成立当成要回答的问题——这是从"刷一次榜"走到"方法可用"的关键一步；
4. **不吹的部分**：没有独占数据、没有产线闭环，就写方法论 + 可复现证据。**诚实在这一栏是加分项**，评委见过太多"替代巨头"的 PPT。

## 六、铁律（材料版）

1. 未实测的数字一律"待实测"，不许填估计值。
2. 外部数字必须标来源（ICME 论文 / 官网 / 市场报告），不同口径要注明（如 KLA 份额 53% vs 32.1% 是两个细分口径）。
3. 口径三句：赛场是华为 ICT 大赛赛题二；尺子是 ICME 冻结榜；我们做的是独立对标，不是参赛获奖。
4. 不写"首创/填补空白"，不写"替代 KLA"，不拿"多智能体编排"当创新点。
5. 每一节写完后问一遍：**删掉"AI/Agent/多智能体"这些词，这段还剩下什么？** 剩下"在晶圆图上定位缺陷、判出严重到哪一档、数字可被公开验证"——这才算写对了。
