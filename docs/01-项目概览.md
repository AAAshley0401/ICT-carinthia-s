# 毫芒 Hairline｜项目概览

更新：2026-10-13。本文件说明项目目标、范围和共同口径；执行事项见 [03-任务计划](03-任务计划.md)。

## 做什么

面向晶圆表面显微图，定位缺陷并判定四档严重度：Acceptable、Marginal NG、NG、Gross NG。系统在华为 ICT 大赛创新赛赛题二指定的 AgentArts 上完成检测、分流、边界样本仲裁，输出放行、复检或返工建议。

**当前状态**：ICME 数据集已申请，尚未取得；模型、评测和 AgentArts 应用均待实测。现有 `src/mock_inference_server.py` 只返回固定演示数据，不读取图片。工作台原型已清理，待真实接口确定后重建。

## 作品边界

| 部分 | 最小交付 |
|---|---|
| 算法内核 | 缺陷定位、类别、严重度和置信度；用同一数据划分记录实验 |
| AgentArts | 调用模型服务，根据结果分流，对低置信度和边界档给出复检路径；保留调用记录 |
| 工作台 | 批次与图片、框/掩码、缺陷记录、处置结论、调用过程 |
| 评测 | mIoU、Macro-F1、QWK 和配置记录；只展示真实可复核的成绩 |

先完成单图闭环，再做批次和增强功能。跨批次阈值校准、解释面板和多模型集成属于后续选项，不是当前承诺。

## 比赛与验证

- **参赛项目**：华为 ICT 大赛创新赛赛题二；AgentArts 是作品平台。
- **外部参考**：ICME 2026 IDA Track 2 已结束。公开榜冠军总分 0.811（mIoU 0.662、Macro-F1 0.673、QWK 0.907），这些是别人的成绩，不是本项目成绩。
- **目标**：先复现官方 baseline，再做单变量改进；是否能在相同测试条件下对标冻结榜，取决于数据许可、测试集和评测入口，当前待确认。不能仅凭训练集或不同数据集上的分数宣称超过冠军。

官方公式：`总分 = 0.2 × mIoU + 0.2 × Macro-F1 + 0.6 × QWK`。官方 baseline 为 YOLOv8-seg 加规则分级；Mask2Former 是冠军方案，二者不能混称。详情以[挑战赛 baseline 仓库](https://github.com/IDAGrandChallenge/idachallenge-baseline)和[论文](https://arxiv.org/abs/2607.04675)为准，复现前仍需核对代码和评测细节。

## 共同规则

1. 自己未跑出的数字写“待实测”；外部数字标来源、数据集和计算口径。
2. ICME 已结束，不暗示本队参加该届赛事或获奖。
3. ICME 数据按许可使用，不进 Git、不再分发；演示不使用保密产线图。
4. MVTec-AD 可用于定位管线自测，但没有 ICME 的四档标签；它的指标与 ICME 榜单分开呈现。
5. 原始数据只读，处理结果另存；每个结论能指向实验配置和输出。

## 风险与转向

| 风险 | 当前做法 |
|---|---|
| ICME 数据或同条件测试入口不可用 | 用公开数据做可复现的定位实验；同步改掉“对标 0.811”的材料口径 |
| GPU 不足 | 先跑可执行的 baseline 小规模流程，再据卡型调整训练规模 |
| AgentArts 接入受限 | 先实现单工具调用与工作流；具体权限以平台实际页面为准 |
| 分级指标因定位改动下降 | 三指标同记，按总分和错误类型判断，不预先宣称收益 |
