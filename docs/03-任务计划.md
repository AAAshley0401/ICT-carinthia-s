## 测试与验收标准

### 功能测试

1. 正常图片：能输出结果，Trace 包含 Detector、Validation、Router。
2. 缺陷图片：能输出较高异常证据和预测区域；没有真实严重度时不得生成正式严重度建议。
3. 边界证据：置信度或概率分布接近阈值时，路径为 `REVIEW` 且 `human_review_required=true`。
4. 推理失败：超时、损坏图片或模型异常时，路径为 `FAILED`，原因包含 `TOOL_ERROR` 或 `INVALID_SCHEMA`。
5. 证据矛盾：高 `defect_probability` 且 `defects=[]` 时，状态为 `INVALID_RESULT`，路径为 `FAILED`，原因是 `EVIDENCE_CONFLICT`。

### 数据与实验验收

- 每个指标都能追溯到数据集、划分、配置、模型版本和代码提交号。
- 未实际跑出的数字写为“待测”，不得手填或使用他人结果。
- MVTec 结果只能标为公开工业数据实验，不能写成 ICME 成绩。
- 原始数据、模型权重和实验输出放在 Git 忽略目录，不提交到仓库。
