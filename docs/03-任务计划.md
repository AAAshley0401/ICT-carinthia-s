# 明察 DefectLens｜任务计划

更新：2026-10-13。团队配置：**1 人算法主责 + 2 人 AI 开发主责**；三人都参与算法工作。

## 分工

| 人 | 主责 | 算法参与 | 近期交付 |
|---|---|---|---|
| A | baseline、分割和分级模型、训练与消融设计 | 主导实验方向，与 C 核对指标 | 跑通公开数据上的定位流程，记录首个真实 mIoU |
| B（你） | AgentArts、工作台、插件接入、演示与材料 | 后处理、置信度和边界样本分析 | 平台最小工具调用及调用记录；工作台流程草图 |
| C | 数据管线、模型服务、评测、实验管理和部署 | 与 A 一起训练、消融、误差分析 | mIoU 脚本与模型 HTTP 接口对齐 |
| 指导老师 | 算力与方向把关 | — | 确认 GPU 卡型、显存和可用时长 |

一个任务有主责，也要有复核：A/C 交叉核对实验与指标；B/C 共同核对接口和 AgentArts 调用；对外数字由至少两人检查。

## 数据到手后

先核对数据与规则 → 复现官方 baseline → 单变量实验 → 接入真实模型 → 形成评测表与演示。若数据或同条件评测入口不可用，改用公开数据集的可复现实验，并在所有材料中明确更换比较对象。时间节点以官方通知为准，临提交前复核。
