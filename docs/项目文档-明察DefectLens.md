> 版本 v1（2026-10-11）。对象：三名队员 + 指导老师。
> 目的：让第一次接触这个项目的人，十分钟内知道"我们在做什么、为什么这么做、各自干什么、下一步动哪"。
> 纪律：本文件里来自外部基准的数字都标了出处；我们自己还没跑出来的数字一律写"待实测"，不许估算充数。

## 一、一句话，先讲清楚

**在半导体晶圆的显微照片里找出缺陷、框出来、判断它严重到哪一档；这套东西作为 Agent 跑在华为 ICT 大赛指定的 AgentArts 平台上；我们用一个公开的冻结榜单，来证明这里面那处硬技术是真的。**

**领域定位**（从大到小四层，第三层起才是我们真正动手的地方）：

| 层 | 是什么 |
|---|---|
| ① 行业 | 制造业**自动化视觉质检**（Automated Visual Inspection）—— 出厂前先看一眼 |
| ② 细分行业 | **半导体与电子制造**：晶圆表面 / PCBA 焊点 / 连接器针脚 / 基板表面 |
| ③ 检测对象 | **晶圆表面显微缺陷**，共 7 类：划痕 · 凹坑 · 颗粒 · 损伤 · 污渍 · 气泡 · 崩边 |
| ④ 我们的落点 | **细粒度严重度分级**：四档 Acceptable / Marginal NG / NG / Gross NG |

**价值在哪**：良率优化（yield optimization）与风险控制 —— 同一道划痕，是放行还是返工，产线靠这个判；现有基准大多只做"有缺陷 / 没缺陷"的二分判断，缺的正是这一层。

拆成三层就清楚了：

- **场景**：晶圆厂或电子产线拍一张显微图，系统说"这里有个缺陷、属于第几档严重度、建议放行 / 复检 / 返工"。
- **平台**：外壳是 AgentArts 上的智能体（赛题二强制要求）。
- **证明**：内核的检测分级能力，在 ICME 2026 的公开冻结榜上跟已经提交的队伍比分数。

为什么非要一把外部尺子：**华为 ICT 大赛没有可以刷的公开算法榜**，评委也没法当场验算我们的模型好不好。所以需要一份"外部证据"——在别人定好的公开基准上、用别人定好的公式，跑出一个数。往届特等奖基本都是这个形状：外面一个平台化系统，里面藏一处真做出来的硬技术。

**必须说准的一句话**：ICME 2026 赛事 2026-04-14 就关闭提交、07-05 已颁奖，我们不能再参赛。我们做的是**在同一个冻结测试集、同一套公式下，超过当届冠军的分数**。这不是退而求其次，但措辞一个字都不能含糊——**绝不能对外暗示我们参赛并获奖**。

## 三、作品长什么样

分两层。外层过赛题，内层拿硬话。

| 层 | 内容 | 作用 |
|---|---|---|
| 外壳 | AgentArts 上的质检智能体：收图 → 调内核 → 汇总 → 给处置建议 | 满足赛题二；三个角色天然分工 |
| 内核 | 筛选 → 分割定位 → 序数分级 → 集成 | 那句"硬话"所在 |

**主视觉**（答辩台上给人看的）：左边一批待检的**晶圆显微图**；中间大图上有缺陷定位框和掩码，配一条四档严重度色带；右边是三个 Agent 的动作与处置建议；底部是和冻结榜对比的面板。

**外壳必须是"真 Agent"，不是套壳。** 这是最容易翻车的地方：如果作品只是"一个检测模型 + 一个调用界面"，评委会问"这跟 AgentArts 有什么关系"。所以三个角色必须有各自的输入输出和动作：

- **检测**：调用内核工具，给出定位、分级与置信度
- **分拣**：读取检测结果，按置信度决定进入常规处置还是送人工 / 送仲裁
- **仲裁**：专门处理卡在边界档的样本，给出可解释的判据

再加上跨批次校准阈值（纯模型没有这个行为）。

![AgentArts 上的三个角色：检测 → 分拣 → 仲裁](figs/fig2-agents.svg)

## 四、技术上要做的事

分四步，每步都有明确的"做完的标志"。

1. **筛选**：先用无监督异常检测把明显正常的图剔掉，再做重检测。榜上筛选拿满分的队都这么干。
2. **定位**：分割模型出每个缺陷实例的掩码。核心指标 mIoU。
3. **分级**：四档严重度 Acceptable / Marginal NG / NG / Gross NG。**关键：这是序数问题，不是并列分类**——要用序数回归（CORN / CORAL 这类），不能用普通 softmax。论文自己承认"Marginal NG 和 NG 分不开"是全场最大障碍，这正好是我们的落点。
4. **集成与后处理**：多模型 / 多尺度结果合并、类别去重、几何规则后处理。

![内核流水线：筛选 → 定位 → 分级 → 集成](figs/fig3-pipeline.svg)

**相对冠军的短板（这是我们要动的地方）**：冠军 0.6 权重的分级已经打到 0.907，几乎到顶；真正低的是 0.2 权重的定位 0.662 和分类 0.673。所以主攻定位和分类，不去 0.907 上硬挤。

**五个开关（消融用）**：更强分割骨干 + 高分辨率多尺度 / 长尾类加权 / 序数头 + 边界重加权 / 决策级集成 / 半监督伪标签。每次只开一个，记录分数变化——这张"开一个开关涨多少分"的表，是答辩最有说服力的东西。

| 2 | EVA | 0.689 | 0.667 | 0.885 | 0.802 |
| 3 | Hebut AI | 0.652 | 0.658 | 0.891 | 0.797 |
| 4 | accle | 0.684 | 0.675 | 0.873 | 0.796 |
| 5 | jcjing | 0.684 | 0.674 | 0.872 | 0.795 |
| 6 | limzero | 0.634 | 0.563 | 0.831 | 0.738 |
| 7 | APC_TDC | 0.546 | 0.666 | 0.790 | 0.716 |

出处：挑战赛官网 leaderboard 与论文。只有 7 支队提交，前五名差距只有 0.016——说明没谁拉开身位，也说明冠军不是不可追。

**官方 baseline（起点，代码公开）**：两个 Track 都用 **YOLOv8-seg** 出实例分割；Track 2 再取 4 个掩码指标（**缺陷面积、框长宽、平均灰度对比度**）**加权规则打分**套四档。

⚠️ **分级是手工规则，不是学出来的**——这就是第一处干净的单变量改进点（换成学习式序数头），也正落在队员 A 的分割本行上。
⚠️ **该仓库只有代码、没有图片**（2026-10-12 核实）；必须自己把数据放进去才能跑。

**冠军方案（追赶目标）**：在 Mask2Former 的解码器上并联一个严重度头，端到端一起训；2100 次迭代、batch 8、2×A100、约 30 分钟、无集成、无外部数据。本质是"复现 + 改一个头"，不是堆算力预训练。

| 队员 B（你） | AgentArts 外壳（三角色编排 + 自定义插件）+ 质检工作台界面 + 可视化 | 对外的脸，对上你的前后端强项 |
| 队员 C（开发，能做 Agent，沾过算法） | 内核工程化 + 评测管线：模型包成 HTTP 服务/插件、mIoU/QWK 脚本、消融调度、数据管线 | 站在 A 与 B 中间的桥，兼算法单点的备份 |

## 八、铁律（每个人都得守）

1. **没跑出来的数字一律写"待实测"**，不许填估计值。对外材料里出现一个编的数，整个项目就不可信了。
2. **口径三句**：赛场是华为 ICT 大赛；尺子是 ICME 冻结榜；ICME 已结束，我们做对标分数，不是参赛获奖。
3. **数据按许可用**：ICME 数据只本地训练、不再分发；MVTec 是研究用途许可，商用得说清楚。
4. **原始数据只读**，所有清洗产物另存。
5. **每个结论都要能指回一个文件或一次实验**，不许"大概是"。
6. **蓝海判据（2026-10-12 立，防反复）**：见下。

### 蓝海判据：为什么"没人做过"在这里不是优点

**一句话：这个赛制下，"没人做过"不是护城河，是负资产。**

三条理由：

1. **函评需要参照系。** 初赛只评书面材料，评委三天看几百份。一个没人做过的题目，他没有东西可对比，**无法判断它难不难、值不值**——这种情况下人的本能是打低分，而不是打高分。反过来，"定位 mIoU 从 0.662 抬到 X"这句话，评委一眼知道难度。**可判定的价值才拿得到分。**
2. **往届特等奖 100% 是熟品类。** WSI 病理加速（华为云已全国落地）、疟疾检测（研究+产品双成熟）、手写中文 OCR、AI 论文反馈（2025 年商业产品一抓一把）。没有一个是"蓝海"。评委评的是完成度、验证彻底性、系统性，不是品类首创。
3. **"没人做过"的三种成因，对学生全是陷阱**：① **不值钱**——做了也没人用，演示再炫也讲不出价值；② **看不见**——没有现成数据和主视觉，答辩台上拿不出东西；③ **做不出来**——缺数据 / 缺算力 / 缺能力，前人试过放弃了。

**真正的蓝海不是"没人做过的领域"，是"没人做好的那一格"。** 领域是红的 ⇒ 有公开尺子、有数据、有懂行人、有参照系；那一格空着 ⇒ 有真贡献可做。ICME 的 mIoU 0.662（全场最低，冠军都没解决）就是这一格。我们站的位置本来就是蓝海，只是不叫那个名字。

**换题的唯一许可条件（沿用旧规，一个字不改）**：脑子里出现一个方向，能同时答上——尺子在哪 / 视觉是什么 / 角色凭什么天然 / 我们哪够得着 / 华为占没占。再加一条：**这个"没人做"是"没人想到"还是"没人做成"？** 前者才可能是蓝海，后者通常是坑。

## 附录 A. 名词速查

- **AgentArts（智果）**：华为云的智能体开发平台。三种模式：单智能体 / 工作流 / 多智能体；能接 MCP、自定义插件、知识库。赛题二强制用它。
- **ICME / Track 2**：一个学术会议办的挑战赛；Track 2 的任务是"缺陷检测 + 严重度分级"，榜单已冻结。
- **mIoU**：分割掩码和标注的重合度，越高越好。
- **Macro-F1**：分类指标，每个类单独算 F1 再平均，防止大类淹没小类。
- **QWK（二次加权 Kappa）**：序数分级的指标，把"NG 判成 Marginal NG"这种相邻错误罚得比"NG 判成 Acceptable"轻，更贴合人对严重度的判断。
- **序数回归 / CORN / CORAL**：把"四档"当成有顺序的量（不是互不相干的四个类），专门做这个的回归头。
- **Mask2Former**：一个通用的图像分割模型，冠军用它当骨架。
- **MVTec-AD**：公开的工业缺陷数据集，我们的备用数据（没有四档严重度标签）。
- **消融（ablation）**：一次只开一个改动，看分数变化多少，用来证明每个改动的贡献。
- **基线（baseline）**：别人已经跑出来的、用来对比的分数。
