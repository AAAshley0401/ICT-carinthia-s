## 一、产品定位

**一句话**：给半导体产线终检环节用的质检智能体——在晶圆表面显微图里定位缺陷、判断严重度档位、给出处置建议，整套跑在 AgentArts 上。

**用户**（按真实度排序，答辩时也按这个顺序讲）：

| 用户 | 场景 | 我们的产品替他做什么 |
|---|---|---|
| 产线质检员 | 终检工位，一批晶圆图要看 | 粗筛掉合格批，只把可疑的和边界的送给人 |
| 质检工程师 | 定标准、复盘误判 | 给出"为什么判这一档"的视觉证据，可回溯 |
| 竞赛评委 | 三分钟看一个作品 | 一眼看懂难点，当场核验数字 |

**产品目标**（按优先级）：
1. 在 ICME 2026 Track 2 冻结榜上给出**可复现的、超过官方 baseline** 的成绩（冲线目标：总分压过当届冠军 0.811，未实测前不写进任何材料）；
2. 在 AgentArts 上完成智能体的构建、编排、部署，**真能跑**；
3. 全链路（上传 → 定位 → 分级 → 处置 → 对标）可现场演示，不靠聊天框。

## 二、功能需求

优先级：**P0 = 没有它作品不成立；P1 = 有了明显加分；P2 = 有余力再做。**

### F1 批次上传与任务管理（P0）
- 一次上传一批图（或指定一个样本集），系统建任务、逐张过、给汇总。
- **验收**：上传 8 张以上不卡死；任务有状态（排队/进行/完成）；完成后出汇总工单。

### F2 缺陷定位（P0）
- 每张图输出缺陷的掩码与边界框，按类别区分（7 类：划痕/凹坑/颗粒/损伤/污渍/气泡/崩边）。
- **验收**：mIoU 指标可在本地评测脚本复算；边界案例（Marginal NG 级）有单独清单。

### F3 严重度分级（P0）
- 每个缺陷判一档：Acceptable / Marginal NG / NG / Gross NG（**序数，不是并列**）。
- **验收**：QWK 可复算；档位判定附置信度；对"判不准"的样本能明确标出。
- **注意**：分级是本产品的核心差异点，不是检测的附属功能。

### F4 边界样本仲裁（P0）
- 专门处理卡在 Marginal NG / NG 边界的样本：给出两侧的视觉证据对比，输出"建议人工复检"而不是硬判。
- **验收**：能筛出一批边界样本并在界面上单独展示；仲裁结论与检测结论可以不同（不同才说明仲裁真的存在）。
- **为什么是 P0**：ICME 论文原话"序数边界消歧仍是最大障碍"——这是全场瓶颈，也是我们主攻点。

### F5 自主分流（P0）
- 按置信度决定处置：高置信合格批直接放行；中置信送人工复检；低置信/边界样本走仲裁。
- **验收**：演示时能看到"同一批图走了不同路径"，不是一律输出结果。**这是 Agent 行为，纯模型没有。**

### F6 可解释（P1）
- 判这一档的依据可视化：哪块区域、什么特征（面积/长宽/灰度对比度等）导向了这个档位。
- **验收**：点任一缺陷，能展示其判档依据。

### F7 跨批次阈值校准（P1）
- 多批数据间累积，动态调整分流阈值；阈值变化有记录、可回看。
- **验收**：连跑两批，第二批的分流阈值与第一批不同（有记录）。**纯模型没有这个行为。**

### F8 对标面板（P1）
- 面板三列：当届冠军 0.811 / 官方 baseline / 本系统（实测后填）。前两列是真数字，不装。
- **验收**：面板数字全部有出处；本系统列在实测前显示"待实测"。

### F9 多角色编排（P0，赛题二硬要求）
- AgentArts 上三个角色：分拣（粗筛）/ 检测（定位+分级）/ 仲裁（边界样本）。各自有工具与职责。
- **验收**：调试窗口的「调用详情」能证明每个角色真的被调用、传参正确。**答辩要现场点开这个。**

## 三、非目标（这份 PRD 最重要的部分）

明确不做什么，防止范围蔓延，也防答辩被一句话问倒：

| 不做 | 为什么 |
|---|---|
| **不做实时产线对接** | 没有真实产线数据与场景，做了也没法验证 |
| **不做设备、不说替代 KLA / AOI** | 无独占数据、无装机闭环，说了是自杀（见 `硬约束`） |
| **不做缺陷图像生成 / 数据合成** | 当届冠军 Track 1 用扩散模型造样本，那是企业队的活，我们不做 |
| **不做多模型集成刷分** | 同上。我们的单变量改进必须干净，否则消融说不清 |
| **不做通用缺陷检测平台** | 只做晶圆这一域的定位+分级，做深不做广 |
| **不追求首创 / 新品类** | 函评需要参照系，"没人做过"在这里是负资产（见 `项目文档` 铁律第 6 条） |

## 四、什么算做完（DoD）

**作品级**：
1. AgentArts 上一个应用，三角色可跑，「调用详情」可截图；
2. 本地评测脚本能对任一模型版本算出 mIoU / Macro-F1 / QWK 三个指标；
3. 公网可访问的演示页面（决赛要求）；
4. 复现报告一份：官方 baseline → 我们的改进，每个开关对应一组数。

**数字级（分档承诺，别混）**：
- 保底：完整复现官方 baseline，三指标与论文同量级；
- 达标：超过官方 baseline，冲进当届中上游；
- 冲线：总分压过 0.811。**未实测前，任何材料里不许出现这个数。**
