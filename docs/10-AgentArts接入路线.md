# AgentArts 接入路线

更新：2026-10-14。AgentArts 公测申请已通过，平台侧可以开始实操。本文只写**下一步做什么、点哪里、填什么、怎么算做完**，不重复 Agent 设计（见 [06-Agent详细设计](06-Agent详细设计.md)）。

## 这一轮的唯一目标

**在 AgentArts 里完成一次真实工具调用，并保存平台原生 Trace。**

理由：初赛材料里"AgentArts 应用真实运行"这条主张，唯一能拿出来的证据就是平台调用记录。没有它，前面所有架构设计在函评里都只是设计稿。所以这一轮不追求三角色多智能体，只追求"链路真的通过平台跑起来过一次"。

## 障碍只有一个：公网地址

AgentArts 是公有云，**访问不到本机** `127.0.0.1:8000`。推理接口必须先有公网可达地址，插件才能配。

| 方案 | 拿到地址的代价 | 适合阶段 | 风险 |
|---|---|---|---|
| 内网穿透（ngrok / cpolar / frp） | 当天，不需服务器 | 先跑通平台流程、验证导入格式 | 免费版域名会变、会断线；不能作为答辩现场依赖 |
| 华为云 ECS（或已有公网机器） | 需购买/申请 + 配 Nginx 反代与证书 | 定型后长期使用、答辩演示 | 有成本与配置工作量 |
| 华为云函数工作流 / API 网关 | 需重新改造接口形态 | 未评估 | 与现有 Python 服务不同源，待确认 |

**建议顺序**：先用内网穿透把"插件导入 → 工具调用 → 调用详情"这条路走通（目的是摸清平台侧流程），再决定是否迁到 ECS。原因是平台侧一定会有需要试错的地方，不应该让云服务器配置成为前置阻塞。

要求：公网地址需要 **HTTPS**（或平台允许的 http），且**接口必须无状态、可重复调用**——插件不支持交互式登录。

## 平台侧操作步骤

### 1. 创建插件（导入现成 OpenAPI）

路径：左侧导航栏 **开发中心 > 组件库 > 插件** → 右上角 **创建插件**（另一入口：**我的资产 > 插件**）。
用 **OpenAPI 导入**，上传 `agentarts/plugin_import_v1.json`（导入前把里面的 `servers[0].url` 换成你的公网地址）。

导入后必须手动处理两件事（平台自身限制）：

- **鉴权不会被自动解析** ⇒ 在插件里手动补鉴权信息，否则工具调用一定因鉴权缺失失败。若要简单，可先让服务不校验鉴权，但正式演示建议加 Bearer token 并在平台配置。
- **参数解析要逐项核对** ⇒ 检查 `image_url` / `sample_id` / `scenario` 三个入参和响应字段是否被正确识别，平台不保证解析无误。

其他限制：平台**只支持导入 GET 与 POST**（本接口是 POST，符合）；单个插件最多 **30 个工具**。

### 2. 在智能体里引用插件并写清楚调用规则

在单智能体编排页添加该插件。提示词里必须**明写"必须先调用工具、不得凭常识直接回答"**——否则模型可能编造检测结果而不调工具，现场演示时调用详情是空的。

### 3. 跑三次并留证

用调试窗口依次跑三个场景，每次点开**「调用详情」**截图/录屏：

| 场景 | 请求 | 预期返回 |
|---|---|---|
| 常规 | `scenario=normal` | `status=success`、`defect_probability` 低、`defects=[]` |
| 边界 | `scenario=boundary` | 高概率 + 一条 `Marginal NG` 缺陷、`severity_confidence` 偏低 |
| 失败 | `scenario=failure` | `status=failed`、`defect_probability=null`、`error=timeout` |

三次都要能看到 `demo_only=true`、`image_analyzed=false`——这证明我们没把模拟输出冒充真实结论。

## 做完的标志

- [ ] 平台插件创建成功，工具能被智能体识别到
- [ ] 三次调用的**调用详情**已保存（含工具名、入参、返回体）
- [ ] 失败路径真实存在且返回 `status=failed`
- [ ] Trace 里能看出 `demo_only=true` / `image_analyzed=false`
- [ ] 以上截图归入初赛材料「AgentArts 应用真实运行」证据项

## 必须记住的三条约束

1. **基础版评估任务只有 10 次** ⇒ 所有消融与指标继续在本地算，平台评估只用于最后确认。
2. **单智能体引用的插件不会自动更新** ⇒ 改接口后要在智能体编排页手动更新插件版本。
3. **现在上平台的仍是 mock**（不读图）⇒ 真实模型达到[接入门槛](../contracts/real_model_integration_gate_v1.md)后重新核对，不得把这一步的截图当作模型能力证据。

## 还没解决、需要决策的点

- 公网地址从哪来（见上表）——**这是当前唯一阻塞**。
- 真实模型上线时图片怎么传给插件：传公网图片 URL 还是 base64？受 ICME 数据许可限制，受限原图不得公开上传，方案需先定。
- 演示时本地工作台（`127.0.0.1:8765`）与云上 AgentArts 如何同屏：是把工作台也部署上云，还是本地展示 + 云端调用。这个影响答辩演示的稳定性，建议定型前定。
