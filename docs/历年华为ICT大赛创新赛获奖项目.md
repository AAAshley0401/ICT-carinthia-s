## 第十届（2025–2026）创新赛 · 全球总决赛特等奖

第十届全球总决赛共有 49 个国家和地区、177 支队伍入围，创新赛全球特等奖共 4 支。

### 武汉理工大学「三缺一等胡队」
- 作品：《基于 MindSpore 的电力线缺陷检测系统》
- 指导老师：段鹏飞｜队员：任奕航、刘冉、王子阳
- 做什么：面向电力巡检的"端—云—网"协同无人机智能检测系统，针对传统巡检高延迟、微小隐性缺陷易漏检的问题
- 技术要点：以搭载昇腾 310B 的香橙派 AI Pro 作边缘算力底座，把重构后的 RT-DETRv2 目标检测算法适配到 MindSpore，通过底层算子等价转换与混合精度编译实现边缘端高效推理；引入 Inner-IoU 与分布焦点损失（DFL）提升微小目标定位精度；可见光与红外热成像双模态像素级融合；采用"边缘小模型实时直出 + 云端 Qwen-VL 大模型复核兜底"的边云协同分流策略
- 结果：26.13 FPS 实时推理，综合检测准确率 97.8%

### 福建师范大学「再看一眼Loss就要爆炸队」
- 作品：《基于昇腾 910B 与 ModelEngine 的 WSI 病理图像推理加速方案》
- 指导老师：方禾｜队员：石宇歆、陈淑萍、张弛张
- 对应赛题：第十届赛题三"昇腾 NPU 算力平台下的 ModelEngine ViT 推理性能提升"
- 技术要点（三级全链路加速）：
  - 知识蒸馏（UNI 大模型作教师 → TinyViT-21M 作学生）压缩模型；AMCT 工具做训练后量化，FP16 混合精度并保护精度敏感层
  - FlashAttention 替换为适配 torch_npu 的昇腾原生融合算子；TorchAir 无损导出后基于 OM 工具链离线编译，开启全量图融合、UB 融合、AIPP 预处理与全局稀疏优化；用 AOE 自动调优
  - Python 多进程异步框架解耦切片解码、图像预处理与 NPU 推理，双缓冲队列让预处理与推理并行
- 结果：推理吞吐达 4,945 FPS，较 FP32 原生 ViT 基准提升近 15 倍；Batch(128) 推理延迟约 24.8 ms
- 同赛季该队先夺得中国总决赛全国一等奖，再拿全球特等奖

### 尼日利亚艾哈迈德·贝洛大学「TeamABU2026」
- 作品：《ParaVision：边缘 AI 赋能，助力疟疾与肠道寄生虫精准检测与诊断》
- 技术要点：双 USB 显微镜采集玻片图像 → OpenCV 预处理 → 在 Ascend 310B4 上用 MindSpore Lite 部署优化版 YOLOv8 与 MobileNet → 基于 openEuler 完全离线运行
- 结果：3 分钟内完成寄生虫检测与自动分类并生成即时诊断报告；支持多语言交互；面向资源匮乏地区的现场快速诊断

### 新加坡国立大学「Remarkably」
- 作品：《Remarkably：AI 论文反馈平台》
- 队员：WU HONGYU、AU YEUNG CHI HUNG JONATHAN、WU HONGYI
- 做什么：AI 驱动的评分平台，帮教师规模化地提供详细、个性化的反馈
- 技术要点：OCR + 多语言 NLP + 计算机视觉分析手写与打印论文，从语法、结构、连贯性、内容质量等维度评估；华为云与 ModelArts 支撑低延迟推理；采用与 MindSpore 兼容、针对华为云优化的 DeepSeek 模型，支持中文作文评分与双语反馈；借助华为 OCR 增强手写中文识别，可直接在纸质试卷上批注

## 从这些作品能看出来的几件事

1. **题目都落在一个具体行业的真痛点上**，没有一个是泛泛的"AI 助手"。电力线巡检、病理图像推理、疟疾寄生虫诊断、作文批改、驾驶员状态感知、岩矿样本分析、农业害虫识别——一个比一个具体。

2. **光调用平台不够，得有自己的一处硬改进**。特等奖队伍基本都在算法或工程上动了真东西：改造损失函数、设计量化与蒸馏策略、多模态融合、异步流水线、图融合与离线编译。评审看的是"技术复合性"这一项能否站住。

3. **能给出硬指标的作品赢面大**。"97.8% 准确率"、"4,945 FPS / 提升近 15 倍"、"3 分钟出诊断报告"——这些数字同时也是"复现红线"要求的东西：答辩说的，代码得能跑出来。

4. **社会价值是加分项，特别是荣誉奖。** 医疗健康、教育普惠、养老助残、农业环保、绿色低碳这几个方向反复出现特等奖，也是 TECH4ALL 数字包容奖、绿色发展奖的集中地。

5. **端—边—云协同的立体架构出现频率很高**。从第八届的巡检机器人到第十届的无人机电力巡检，都是"边缘设备负责实时、云端大模型负责兜底复核"这个套路。
