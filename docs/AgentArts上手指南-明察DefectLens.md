# AgentArts 上手指南（明察 DefectLens）

> 用途：让全队今天就能在 AgentArts 上点出一个跑得起来的东西，并说清"我们的模型怎么接进去"。
> 来源：华为云帮助中心《搭建第一个智能体》（support.huaweicloud.com/qs-agentarts0/agentarts_04_0002.html）、《自定义接入 MCP》（support.huaweicloud.com/lowcode-agentarts/agentarts_05_0136.html）、《添加 MCP 服务》。以下凡"官方原文"字样均为文档原话，其余为我们的推论。
> 说明：平台在公测期，界面与限额可能变。**临操作前以平台实际页面为准**，本文件只保证"路径和坑"是对的。

---

## 〇、先记住两句话

1. **AgentArts 不是"上传作品的地方"**，是干活的地方——你在里面**建、编排、部署一个真能跑的智能体**。交作品是另一套材料（见 `起跑清单` §〇之三）。
2. **有一条硬约束会直接决定我们怎么接模型**：AgentArts 是公有云，**只能通过公网访问外部服务，连不到内网或本地**（官方原文）。我们现在那个跑在 `127.0.0.1:8000` 的模拟接口，**平台够不着**。解决方式见第四节。

---

## 一、准备工作（一次性，三步）

官方原文路径是三步：

1. 注册华为账号并开通华为云（官网右上角"注册"）
2. **实名认证** —— 个人账号走"个人实名认证"即可，不需要企业资质
3. 登录 AgentArts 平台，按提示开通 AgentArts 服务

补充两点（我们核到的）：

- 平台在**公测期，基础版限时免费**（权益与限额以平台页面为准，我们没登录核过）。
- **基础版限制**：官方文档写明"基础版创建评估任务 10 次后，无法继续创建新的评估任务"。我们要做多组消融与评测，**这 10 次要省着用**——先在本地算完指标，再拿平台评估做确认，而不是每次调参都上平台跑。

---

## 二、五步：跑通第一个智能体（官方"搭建第一个智能体"同路径）

| 步骤 | 点哪里 | 做什么 | 我们填什么 |
|---|---|---|---|
| 1 创建 | 总览页 →「快速创建智能体」卡片 →「立即创建」 | 填名称 + 描述 | 名称：明察质检台（或分拣员/检测员/仲裁员，视角色）；描述写它接哪一段活 |
| 2 配模型 | 配置页「模型」下拉框 | 选模型（官方示例用 DeepSeek-V3） | 先用平台预置模型；首次用需先对模型做鉴权 |
| 3 配技能 | 「技能」区：MCP 服务 / 插件 / 工作流 / 知识库 | 把能力装进去 | **这一步就是我们接自己模型的地方**，见第三节 |
| 4 调提示词 | 「提示词」面板 | 写角色、任务、约束、输出格式 | 关键：**必须写清"什么时候调用哪个工具"**，否则智能体可能凭默认逻辑自己编答案而不调工具（官方原话） |
| 5 调试发布 | 右侧「预览调试」→ 右上角「提交版本」 | 实时对话验证 → 提交版本 → 分享 | 「渠道管理」里选「网页」发布，拿到可访问地址；「查看 API」可拿接口信息 |

**调试窗口能看什么**（这一步别跳过）：对话里可以点开「调用详情」，**看到智能体到底调了哪个工具、传了什么参数**。答辩时"平台自带可观测性"就是要拿这个当证据——证明工具是真被调用的，不是模型嘴里说说。

## 三、把我们自己的东西接进去：两条路

我们手上有一个 REST 接口（`src/mock_inference_server.py`：`POST /v1/inspect`，输入 `image_url` + 可选 `sample_id`，返回 `grade` / `confidence` / `defects`）。**它不是 MCP 协议**，所以有两条接法：

| | 路 A：插件（Plugin） | 路 B：MCP 服务 |
|---|---|---|
| 怎么造 | 「开发中心 > 组件库 > 插件」→**基于 API 创建插件**（也可基于 JSON 文件导入 API） | 「我的资产 > MCP」→ 创建 MCP：平台模板 / 空白创建 / 第三方服务安装 / **自定义接入** |
| 适配我们的接口 | **直接**：填 REST 地址 + 参数与返回的 schema，包成一个「工具」 | 需要把服务**包装成 MCP 协议**（SSE 或 streamableHttp）才能接入 |
| 工作量 | 小 | 中（多写一层 MCP server） |
| 官方定位 | 插件 = 一个 API 工具 | MCP = 标准化外部能力连接器 |

**我们的走法：先 A 后 B。**

- **先走 A（插件）**：当天就能把 `/v1/inspect` 挂上去，把"AgentArts 调我们自己接口"这条链路打通——这才是那句"这跟 AgentArts 有什么关系"的答案。
- **后补 B（MCP）**：决赛材料里要交「自定义 Skill / MCP 服务说明」，所以最终形态应该有 MCP 这一层。但**先别卡在这**，A 通了再包 B。

MCP 那条路的关键参数（官方原文，先记着）：

- 安装方式支持 **NPX / UVX / SSE / streamableHttp**；接入自主开发的远程服务用 **SSE 或 streamableHttp**。
- 服务地址**只支持 HTTP 和 HTTPS**，必须是标准 URL，**对应的 IP 默认不应为内网**。
- 需要鉴权就提前备好 API Key / OAuth 凭据；我们现在的 mock **无鉴权**，选"无需鉴权"。
- **一个应用里 MCP 服务数量 ≤ 5 个**——我们三个角色，够用，但别乱加。

## 四、那条会卡死我们的硬约束：公网地址

**官方原文**：

> 如果需要接入自主开发或私有部署的 MCP 服务，请确保该服务**已完成部署并可通过公网地址访问**。由于 AgentArts 为公有云服务，平台需要通过公网与 MCP 服务建立连接，**无法直接访问内网或本地环境中的服务**。

翻译成我们的话：

- `python src/mock_inference_server.py` 起的服务监听 `127.0.0.1:8000` —— **平台访问不到，挂不上去。**
- 要么部署到**有公网 IP 的云服务器**，要么用**内网穿透**把它暴露成一个公网 HTTPS 地址。
- 提示：团队《开发规范》里本来就有 **ngrok 内网穿透**的部署手册（规范第七章之后那几节），这条可以直接复用；同类工具还有 cpolar、frp、花生壳。
- 同理，决赛要求交的「可在线访问和交互的 Demo 页面地址」也需要公网部署——**两件事是同一个问题**，一次解决。

**结论**：在把服务挪到公网之前，AgentArts 侧只能先搭"不带我们模型的空壳"（用平台预置的 MCP / 插件练手）。**"把服务挪到公网"是下一个必做动作**，排期要提前，别等到决赛前。

## 五、最终要落成的形态：三角色

赛题二要求的是"基于 AgentArts 构建与运行的完整流程"，配套三件事我们已定：分拣 / 检测 / 仲裁三个角色。

平台给的三种模式，**按风险递增走**：

1. **单智能体**（最先跑）——先做一个角色，把"调我们的插件 → 拿到分级结果 → 输出处置建议"跑通。**这是今天的目标。**
2. **工作流（Workflow）**——如果多智能体的编排一时搭不顺，**用工作流兜底**：把"筛选 → 检测 → 分级 → 处置"串成固定顺序的节点，同样满足赛题。（这也是我们早先定好的降级方案。）
3. **多智能体**——最终形态：三个角色各自有提示词、工具与职责，能互相交接。

**注意**：不管哪种模式，**工具调用必须真发生**。提示词里要明写调用规则（官方原文提醒：不在指令里设调用规则，智能体可能自己编答案而不调工具）。答辩演示时要现场点开「调用详情」。

---

## 六、今天半小时能做的最小动作

不依赖数据、不依赖队友，一个人就能做完：

1. 注册 + 实名认证 + 开通 AgentArts（约 10 分钟）
2. 建一个单智能体，名称"明察质检台"，描述写"接收晶圆显微图，调用检测工具，输出缺陷与严重度档位"
3. 加一个**平台预置**的 MCP 或插件（官方示例里有"必应搜索""本草纲目"这类），只为验证"工具能被调用"
4. 在调试窗口问一句，**点开「调用详情」确认工具真被调用**——这一条跑通，平台就算入门了
5. 提交版本 → 渠道管理 → 发布为网页，拿到地址

**做完这五步，你手上就有**：一个能跑的 AgentArts 应用 + 一个公网可访问的页面 + 一份"调用详情"截图（将来是答辩证据）。

**还没做的**：把 `/v1/inspect` 接到公网并挂成插件。这需要先解决第四节那件事。

---

## 七、待核清单（操作前逐个确认）

1. 开通 AgentArts 是否要求**企业实名**——我们按"个人实名"准备，若卡住需换路径（开源版 OpenJiuwen 与商用内核同源，可作备选）。
2. 基础版**是否限时免费**、免费额度到什么时候；评估任务的 10 次限额是否仍然生效。
3. 「插件（基于 API 创建）」的入参/出参 schema 具体怎么填——官方这个页面我们还没逐行读，**操作时以页面指引为准**。
4. 「多智能体」的创建入口与角色间交接怎么配——官方有专门页面（创建多智能体应用 / 发布多智能体应用为 API），**要建三角色之前先读一遍**。
5. 公网方案选型：云服务器 vs 内网穿透，谁出钱、谁维护——**这是排期上的前置项**。
