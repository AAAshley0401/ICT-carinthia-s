# 页面原型

- [工作台新版.html](工作台新版.html)：当前设计稿。主页面展示批次、图像、缺陷记录、分级处置和 Agent 处理链；评测证据在独立弹层。
- [明察-DefectLens.html](明察-DefectLens.html)：早期概念稿，保留作对照。

新版可直接用浏览器打开。可以切换模拟样本、显示或隐藏框和掩码、点击缺陷行定位、打开评测弹层，也可以上传本地图片预览。上传后不会生成检测结果，也不会把图片发送到服务端。

当前图像、标注、分级和 Agent 记录都是模拟内容。下一阶段应接入真实推理服务与 AgentArts 调用记录，再替换相应区域；模型指标只使用真实评测结果。

[image-prompts.md](image-prompts.md) 记录了拟用 Image 2.5 生成整页视觉稿和显微演示图的具体要求。目前尚未生成图像文件。
