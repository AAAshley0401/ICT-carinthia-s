重建时的落点要求（来自 `../docs/01-项目概览.md` 与 `../docs/02-技术方案.md`）：

- 主页面展示批次、图像、缺陷记录、分级处置和 Agent 处理链；评测证据放在独立弹层。

- 可直接用浏览器打开，不依赖服务端；上传本地图片仅作预览，不生成检测结果，不发送到服务端。
